# Robotic Hand for Humanoid

**Goal:** Update structure from previous 1 DOF to 5 DOF by individually actuating each finger + thumb separately. 

Currently project uses 5 hobby servo motors - 1 attached to the pinky + ring, 3 attached to the remaining fingers and 1 attached to the thumb hinge. 
Each servo is aligned via an elastic threading and pulled with fishing wire + servo.
The fingers are CAD printed with hinges in place, interference fit into the palm and then threaded. 

ESP32-C3 used for the microcontroller with arduino ide setup. Currently battery operated with motor driver attached to prevent current overload.
